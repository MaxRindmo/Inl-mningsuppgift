    Matplaneraren
##	Om	sidan
Vad	handlar	sidan	om,	och	vem	är	den	till	för?	Två–tre	meningar.
Receptsida för olika maträtter där man kan se olika recept och ingredienser. 
Tanken är att sidan ska kunna användas både för att kunna kolla efter recept om man har dålig fantasi men även använda recepten som inköpslistor.

Den grundliga designen i repot är inte samma som utseendet på sidan. Skissen skapades för en sida som var en produktsida, total ändring gjordes och sidan byggdes istället som en receptplanerare.
##	Funktionalitet
Vad	kan	besökaren	göra	på	sidan?	Vilken	fil	och	vilka	funktioner	sköter	det?
Besökaren kan hitta och utforska nya recept, markera instruktionerna för att följa steg under tiden som maten lagas. Besökaren kan även använda receptet för att bocka i eller ur ingredienserna för att använda detta som en checklista för ingredienser.
